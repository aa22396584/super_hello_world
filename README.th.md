# รวม Hello World หลายภาษา

[English](README.md) | [繁體中文](README.zh-TW.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | [Bahasa Indonesia](README.id.md) | [ไทย](README.th.md)

ชุดตัวอย่าง `Hello, World!` มากกว่า 60 ภาษา แบ่งตามพาราไดม์เพื่อให้เปรียบเทียบไวยากรณ์และวิธีรันได้ง่าย

## 🌟 ภาพรวม

- ครอบคลุมภาษาแบบคอมไพล์ แบบอินเทอร์พรีต ฟังก์ชันนัล สคริปต์ และอื่น ๆ
- แต่ละภาษามีซอร์สโค้ดพร้อมคำอธิบายและ README แยก
- มีการทดสอบอัตโนมัติเพื่อยืนยันผลลัพธ์ `Hello, World!`
- รายการภาษาทั้งหมดและคำสั่งโปรดดูที่ README ภาษาอังกฤษ

## 🚀 เริ่มต้นอย่างรวดเร็ว

ใช้สคริปต์เดียวเพื่อรันภาษาที่ต้องการ:

```bash
# รันภาษาที่ระบุ
./run.sh python

# รันด้วยชื่อเต็ม
./run.sh "C++"

# ดูรายการภาษา / หมวดหมู่
./run.sh --list
./run.sh --category compiled

# รันทั้งหมด (ต้องติดตั้งรันไทม์)
./run.sh --all
```

## 🧪 การทดสอบ

```bash
# ทดสอบทั้งหมด
./test.sh

# ทดสอบเฉพาะภาษา หรือหมวดหมู่
./test.sh rust
./test.sh --category functional

# ทดสอบเฉพาะที่ติดตั้งแล้ว
./test.sh --available-only

# แสดงรายละเอียดมากขึ้น
./test.sh --verbose
```

## 🤝 การมีส่วนร่วม

1) สร้างไดเรกทอรีในหมวดที่ถูกต้องและเพิ่ม `hello.{ext}`  
2) เขียน README ในไดเรกทอรีนั้น (วิธีติดตั้งและรัน)  
3) อัปเดต `languages.json` ด้วยเมทาดาต้า  
4) รัน `./test.sh your-language` เพื่อตรวจสอบ  

รายละเอียดอยู่ใน `CONTRIBUTING.md`
