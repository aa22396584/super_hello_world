## 語言簡介

Elixir 是一個動態的函數式程式語言，運行在 Erlang VM (BEAM) 上。它結合了 Erlang 的並發能力和現代化的語法設計。

## 安裝說明

### macOS
```bash
brew install elixir
```

### Linux (Ubuntu/Debian)
```bash
sudo apt-get update
sudo apt-get install elixir
```

### Windows
下載並安裝 [Elixir](https://elixir-lang.org/install.html)

## 執行方式

```bash
elixir hello.ex
```

## 程式碼說明

- `IO.puts` - Elixir 的標準輸出函數，自動添加換行符
- Elixir 使用 `#` 作為單行註解
- 不需要定義模組或主函數，頂層程式碼會直接執行
