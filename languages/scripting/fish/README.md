Fish (Friendly Interactive SHell) is a smart and user-friendly command line shell for Linux, macOS, and other Unix-like systems.

## Installation

### macOS
```bash
brew install fish
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install fish

# Fedora
sudo dnf install fish

# Arch
sudo pacman -S fish
```

## Running the Program

Make the script executable and run it:

```bash
chmod +x hello.fish
./hello.fish
```

Or run it directly with fish:

```bash
fish hello.fish
```

## Expected Output

```
Hello, World!
```
