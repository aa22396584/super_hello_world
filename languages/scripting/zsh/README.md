# Zsh Hello World

Zsh (Z Shell) is a Unix shell that can be used as an interactive login shell and as a command interpreter for shell scripting.

## Installation

### macOS
Zsh is the default shell on macOS Catalina and later.

```bash
zsh --version
```

### Linux
Install via package manager:

```bash
# Ubuntu/Debian
sudo apt install zsh

# Fedora
sudo dnf install zsh

# Arch
sudo pacman -S zsh
```

## Running the Program

Make the script executable and run it:

```bash
chmod +x hello.zsh
./hello.zsh
```

Or run it directly with zsh:

```bash
zsh hello.zsh
```

## Expected Output

```
Hello, World!
```
