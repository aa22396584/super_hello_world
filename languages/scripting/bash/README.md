# Bash Hello World

Bash (Bourne Again SHell) is a Unix shell and command language widely used for scripting and automation.

## Installation

### macOS
Bash comes pre-installed on macOS.

```bash
bash --version
```

### Linux
Bash is typically pre-installed on most Linux distributions.

```bash
bash --version
```

### Windows
Use WSL (Windows Subsystem for Linux) or Git Bash.

## Running the Program

Make the script executable and run it:

```bash
chmod +x hello.sh
./hello.sh
```

Or run it directly with bash:

```bash
bash hello.sh
```

## Expected Output

```
Hello, World!
```
