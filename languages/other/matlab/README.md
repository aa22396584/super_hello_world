## 語言簡介

MATLAB (Matrix Laboratory) 是由 MathWorks 開發的數值計算環境和程式語言。MATLAB 廣泛用於工程、科學研究、資料分析和演算法開發。

## 特點

- 強大的矩陣運算
- 豐富的工具箱
- 優秀的資料視覺化
- 互動式開發環境
- 適合原型開發

## 安裝

### 商業版本
MATLAB 是商業軟體，需要購買授權：
https://www.mathworks.com/products/matlab.html

### 開源替代方案 (Octave)

#### macOS
```bash
brew install octave
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install octave
```

#### Windows
下載並安裝 GNU Octave：
https://www.gnu.org/software/octave/

## 執行

```bash
# 使用 MATLAB
matlab -batch "run('hello.m')"

# 或使用 Octave（開源替代方案）
octave hello.m
```

## 程式碼說明

- `%`: 註解符號
- `disp()`: 顯示文字或變數內容
