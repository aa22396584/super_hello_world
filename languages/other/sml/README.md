## 語言簡介

Standard ML (SML) 是一種通用的函數式程式語言，具有編譯時型別檢查和型別推斷。ML 家族包括 Standard ML、OCaml 等語言。

## 特點

- 函數式程式設計
- 強大的型別系統
- 型別推斷
- 模式匹配
- 模組系統

## 安裝

### macOS
```bash
# 使用 Homebrew 安裝 SML/NJ
brew install smlnj
```

### Linux (Ubuntu/Debian)
```bash
sudo apt update
sudo apt install smlnj
```

### Windows
下載並安裝 SML/NJ：
https://www.smlnj.org/

## 執行

```bash
# 使用 SML/NJ 執行
sml hello.sml

# 或使用 MLton 編譯
mlton hello.sml
./hello
```

## 程式碼說明

- `(* ... *)`: 註解
- `print`: 輸出字串函數
- `\n`: 換行字元
