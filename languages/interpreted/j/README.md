# J Hello World

## 語言簡介

J 是一種陣列程式語言，由 Kenneth E. Iverson 和 Roger Hui 於 1990 年代初開發。J 是 APL 的後繼者，但使用 ASCII 字元而非特殊符號，使其更容易在標準鍵盤上輸入。
