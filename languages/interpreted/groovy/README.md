# Groovy Hello World

## 語言簡介

Groovy 是一種基於 Java 虛擬機（JVM）的動態程式語言。由 James Strachan 於 2003 年創建，Groovy 結合了 Python、Ruby 和 Smalltalk 的特性，同時與 Java 完全相容。

## 安裝說明

### macOS
```bash
brew install groovy
```

### Linux
```bash
# 使用 SDKMAN 安裝（推薦）
curl -s "https://get.sdkman.io" | bash
sdk install groovy

# Ubuntu/Debian
sudo apt install groovy

# Arch Linux
sudo pacman -S groovy
```

### Windows
從官網下載：https://groovy.apache.org/download.html

## 執行說明

```bash
groovy hello.groovy
```

### 預期輸出
```
Hello, World!
```
