## 語言簡介

APL（A Programming Language）是一種陣列程式語言，由 Kenneth E. Iverson 於 1960 年代開發。APL 以其獨特的符號系統而聞名，使用特殊的數學符號來表達運算，特別適合數學和科學計算。

## 安裝說明

### macOS/Linux/Windows
```bash
# 使用 Dyalog APL（免費個人版）
# 從官網下載：https://www.dyalog.com/download-zone.htm

# 或使用 GNU APL
# macOS
brew install gnu-apl

# Linux
sudo apt install gnu-apl  # Ubuntu/Debian
```

## 執行說明

```bash
# 使用 Dyalog APL
dyalog hello.apl

# 或使用 GNU APL
apl -f hello.apl
```

### 預期輸出
```
Hello, World!
```
