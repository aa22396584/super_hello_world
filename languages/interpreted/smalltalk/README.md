# Smalltalk Hello World

## 語言簡介

Smalltalk 是一種物件導向的動態型別程式語言，由 Alan Kay 等人在 Xerox PARC 於 1970 年代開發。Smalltalk 是第一個真正的物件導向程式語言，對後來的許多語言產生了深遠影響。

## 安裝說明

### macOS
```bash
brew install gnu-smalltalk
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install gnu-smalltalk

# Fedora
sudo dnf install smalltalk

# Arch Linux
sudo pacman -S smalltalk
```

### Windows
從官網下載 GNU Smalltalk：https://www.gnu.org/software/smalltalk/

## 執行說明

```bash
gst hello.st
```

### 預期輸出
```
Hello, World!
```
