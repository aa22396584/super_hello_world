## 語言簡介

PHP（Hypertext Preprocessor）是一種廣泛使用的開源伺服器端腳本語言，特別適合 Web 開發。由 Rasmus Lerdorf 於 1994 年創建，PHP 可以嵌入 HTML 中，並在伺服器端執行。

## 安裝說明

### macOS
```bash
brew install php
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install php-cli

# Fedora
sudo dnf install php-cli

# Arch Linux
sudo pacman -S php
```

### Windows
從官網下載：https://windows.php.net/download/

## 執行說明

```bash
php hello.php
```

### 預期輸出
```
Hello, World!
```
