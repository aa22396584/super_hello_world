## 語言簡介

R 是一種專為統計計算和圖形設計的程式語言和軟體環境。由 Ross Ihaka 和 Robert Gentleman 於 1993 年創建，R 在資料分析、統計建模和資料視覺化領域廣泛使用。

## 安裝說明

### macOS
```bash
brew install r
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install r-base

# Fedora
sudo dnf install R

# Arch Linux
sudo pacman -S r
```

### Windows
從官網下載：https://cran.r-project.org/bin/windows/base/

## 執行說明

```bash
Rscript hello.r
```

### 預期輸出
```
Hello, World!
```
