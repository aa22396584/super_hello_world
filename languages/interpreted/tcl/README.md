# Tcl Hello World

## 語言簡介

Tcl（Tool Command Language）是一種腳本語言，由 John Ousterhout 於 1988 年創建。Tcl 設計簡單且易於嵌入應用程式中，常與 Tk 圖形介面工具包一起使用。

## 安裝說明

### macOS
```bash
# macOS 通常預裝 Tcl
tclsh --version

# 或使用 Homebrew 安裝
brew install tcl-tk
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install tcl

# Fedora
sudo dnf install tcl

# Arch Linux
sudo pacman -S tcl
```

### Windows
從官網下載：https://www.tcl.tk/software/tcltk/

## 執行說明

```bash
tclsh hello.tcl
```

### 預期輸出
```
Hello, World!
```
