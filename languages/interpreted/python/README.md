## 語言簡介

Python 是一種高階、解釋型、通用的程式語言，以其簡潔易讀的語法而聞名。由 Guido van Rossum 於 1991 年創建，Python 強調程式碼的可讀性，並允許程式設計師用更少的程式碼表達概念。

## 安裝說明

### macOS
```bash
# 使用 Homebrew 安裝
brew install python3

# 或從官網下載安裝包
# https://www.python.org/downloads/
```

### Linux
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3

# Fedora
sudo dnf install python3

# Arch Linux
sudo pacman -S python
```

### Windows
從官網下載安裝包：https://www.python.org/downloads/

確保在安裝時勾選 "Add Python to PATH"

## 執行說明

### 直接執行
```bash
python3 hello.py
```

或者（如果 python3 是預設版本）：
```bash
python hello.py
```

### 預期輸出
```
Hello, World!
```

## 語法說明

- `print()`: Python 的內建函數，用於輸出文字到標準輸出
- 字串可以使用單引號 `'` 或雙引號 `"` 包圍
- Python 使用縮排來定義程式碼區塊（此範例無需縮排）
- 註解使用 `#` 符號
