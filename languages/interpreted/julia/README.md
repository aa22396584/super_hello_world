## 語言簡介

Julia 是一種高階、高效能的動態程式語言，專為科學計算和數值分析設計。於 2012 年發布，Julia 結合了 Python 的易用性和 C 的執行速度，在資料科學和機器學習領域越來越受歡迎。

## 安裝說明

### macOS
```bash
brew install julia
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install julia

# Fedora
sudo dnf install julia

# Arch Linux
sudo pacman -S julia
```

### Windows
從官網下載：https://julialang.org/downloads/

## 執行說明

```bash
julia hello.jl
```

### 預期輸出
```
Hello, World!
```
