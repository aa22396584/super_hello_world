# Perl Hello World

## 語言簡介

Perl 是一種高階、通用、解釋型的動態程式語言。由 Larry Wall 於 1987 年創建，Perl 以其強大的文字處理能力而聞名，常用於系統管理、Web 開發和網路程式設計。

## 安裝說明

### macOS
```bash
# macOS 通常預裝 Perl
perl --version

# 或使用 Homebrew 安裝最新版本
brew install perl
```

### Linux
```bash
# 大多數 Linux 發行版預裝 Perl
perl --version

# Ubuntu/Debian
sudo apt install perl

# Fedora
sudo dnf install perl

# Arch Linux
sudo pacman -S perl
```

### Windows
從官網下載 Strawberry Perl：https://strawberryperl.com/

## 執行說明

```bash
perl hello.pl
```

### 預期輸出
```
Hello, World!
```
