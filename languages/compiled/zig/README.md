# Zig Language - Hello World

## 語言簡介

Zig 是一種通用程式語言和工具鏈，專注於穩健性、最佳化和可維護性。Zig 旨在成為 C 的現代替代品，提供更好的安全性和更簡潔的語法。

## 安裝說明

### macOS
```bash
brew install zig
```

### Linux
```bash
# 從官網下載二進位檔案
# https://ziglang.org/download/
```

### Windows
下載並安裝 [Zig](https://ziglang.org/download/)

## 編譯說明

```bash
zig build-exe hello.zig
```

## 執行說明

```bash
./hello
```

或直接執行：
```bash
zig run hello.zig
```

## 預期輸出

```
Hello, World!
```
