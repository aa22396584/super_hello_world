# C# Language - Hello World

## 語言簡介

C# 是由 Microsoft 開發的物件導向程式語言，於 2000 年發布。C# 是 .NET 平台的主要語言，廣泛用於 Windows 應用程式、遊戲開發（Unity）和企業應用。

## 安裝說明

### macOS / Linux / Windows
```bash
# 安裝 .NET SDK
# 訪問 https://dotnet.microsoft.com/download
```

### macOS (使用 Homebrew)
```bash
brew install --cask dotnet-sdk
```

## 編譯說明

```bash
csc hello.cs
```

或使用 .NET CLI：
```bash
dotnet build
```

## 執行說明

```bash
./hello.exe
```

或：
```bash
dotnet run
```

## 預期輸出

```
Hello, World!
```
