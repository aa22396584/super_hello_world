## 語言簡介

V 是一種簡單、快速且安全的編譯型程式語言，用於開發可維護的軟體。V 的語法類似 Go，編譯速度極快，並且沒有垃圾回收器。

## 安裝說明

### macOS / Linux
```bash
git clone https://github.com/vlang/v
cd v
make
sudo ./v symlink
```

### macOS (使用 Homebrew)
```bash
brew install vlang
```

## 編譯說明

```bash
v hello.v
```

## 執行說明

```bash
./hello
```

或直接執行：
```bash
v run hello.v
```

## 預期輸出

```
Hello, World!
```
