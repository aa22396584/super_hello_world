# Swift Language - Hello World

## 語言簡介

Swift 是由 Apple 開發的程式語言，於 2014 年發布。Swift 設計用於 iOS、macOS、watchOS 和 tvOS 應用開發，以其安全性、效能和現代語法而聞名。

## 安裝說明

### macOS
```bash
# Swift 已包含在 Xcode 中
xcode-select --install
```

### Linux
```bash
# 訪問 https://swift.org/download/ 下載對應版本
```

## 編譯說明

```bash
swiftc hello.swift -o hello
```

## 執行說明

```bash
./hello
```

或直接執行：
```bash
swift hello.swift
```

## 預期輸出

```
Hello, World!
```
