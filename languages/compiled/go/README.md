## 語言簡介

Go（又稱 Golang）是由 Google 開發的程式語言，於 2009 年發布。Go 設計目標是簡潔、高效且易於並發程式設計，特別適合建構網路服務和分散式系統。

## 安裝說明

### macOS
```bash
brew install go
```

### Linux (Ubuntu/Debian)
```bash
sudo apt-get update
sudo apt-get install golang-go
```

### Linux (Fedora/RHEL)
```bash
sudo dnf install golang
```

### Windows
下載並安裝 [Go installer](https://go.dev/dl/)

## 編譯說明

```bash
go build hello.go
```

## 執行說明

```bash
./hello
```

或直接執行（不產生執行檔）：
```bash
go run hello.go
```

## 預期輸出

```
Hello, World!
```
