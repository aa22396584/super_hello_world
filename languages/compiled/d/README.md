# D Language - Hello World

## 語言簡介

D 是一種系統程式語言，結合了 C++ 的效能和現代語言的便利性。D 支援多種程式設計範式，包括物件導向、函數式和泛型程式設計。

## 安裝說明

### macOS
```bash
brew install dmd
```

### Linux (Ubuntu/Debian)
```bash
sudo apt-get install dmd-compiler
```

### Windows
下載並安裝 [DMD Compiler](https://dlang.org/download.html)

## 編譯說明

```bash
dmd hello.d
```

## 執行說明

```bash
./hello
```

## 預期輸出

```
Hello, World!
```
