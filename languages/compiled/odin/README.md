## 語言簡介

Odin 是一種通用程式語言，專注於簡潔性、效能和現代系統程式設計。Odin 的設計理念是提供比 C 更好的替代方案，同時保持簡單和可預測性。

## 安裝說明

### macOS / Linux
```bash
git clone https://github.com/odin-lang/Odin
cd Odin
make
```

### Windows
參考 [官方安裝指南](https://odin-lang.org/docs/install/)

## 編譯說明

```bash
odin build hello.odin -file
```

## 執行說明

```bash
./hello
```

或直接執行：
```bash
odin run hello.odin -file
```

## 預期輸出

```
Hello, World!
```
