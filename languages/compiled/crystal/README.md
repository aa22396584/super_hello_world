## 語言簡介

Crystal 是一種靜態型別的編譯型程式語言，語法類似 Ruby。Crystal 結合了 Ruby 的優雅語法和 C 的效能，並提供型別推斷和編譯時檢查。

## 安裝說明

### macOS
```bash
brew install crystal
```

### Linux (Ubuntu/Debian)
```bash
curl -fsSL https://crystal-lang.org/install.sh | sudo bash
```

### Windows
使用 WSL (Windows Subsystem for Linux)

## 編譯說明

```bash
crystal build hello.cr
```

## 執行說明

```bash
./hello
```

或直接執行：
```bash
crystal run hello.cr
```

## 預期輸出

```
Hello, World!
```
