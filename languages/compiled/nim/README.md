## 語言簡介

Nim 是一種靜態型別的編譯型程式語言，結合了 Python 的簡潔語法和 C 的效能。Nim 編譯為 C、C++ 或 JavaScript，適合系統程式設計和應用開發。

## 安裝說明

### macOS / Linux
```bash
curl https://nim-lang.org/choosenim/init.sh -sSf | sh
```

### macOS (使用 Homebrew)
```bash
brew install nim
```

### Windows
下載並安裝 [Nim installer](https://nim-lang.org/install.html)

## 編譯說明

```bash
nim c hello.nim
```

## 執行說明

```bash
./hello
```

## 預期輸出

```
Hello, World!
```
